#  Smart Farming Advisor

A web application that helps farmers make **data-driven farming decisions** using crop selection, weather inputs, and AI-powered guidance.

---

## 🚀 Features
- 🌾 Select crops (Rice, Tomato, Maize, etc.)
- 📍 Input location or manual weather data  
- 💧 Get irrigation, fertilizer & pest recommendations  
- 🤖 AI chat for simple farming advice  
- 📊 Dashboard with weather, soil tips & alerts  
- 🕓 History tracking of previous sessions  

---

## 🛠️ Tech Stack
- **Frontend:** React (Vite) + Tailwind CSS  
- **Backend:** Supabase Edge Functions  
- **Database:** Supabase
